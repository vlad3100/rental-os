Format: 30 min call or visit, notes in the template (M1), record only with consent.

## Core questions (ask about the last listing)

1. Tell me about the last flat you let. When did it go live, and when was the lease signed?
2. How many inquiries came in? Through which channels?
3. What did you do with them, step by step? Who did it?
4. How long did that take in total? Which part was most annoying?
5. Which questions came up again and again?
6. How did you organise viewings? What went wrong?
7. Did you miss or answer late any good inquiry? How did you notice?
8. Which tools do you use (portal inbox, CRM, email, Excel)? What do you pay?
9. What would you never hand over to software? Why?
10. If this took half the time next month, what would that be worth to you?

**Do not ask:** "Would you use an AI tool for this?" or "Do you like the idea?"

## Signal strength (quick version; full rubric in M1)

- **Strong:** gives concrete numbers, describes recent pain, already pays for a workaround, offers a real listing for a pilot.
- **Medium:** confirms pain but cannot quantify; interested in a demo.
- **Weak:** hypothetical interest only; problem solved by an assistant or the CRM.
